## 2. 定案／裁決（代理指揮已拍板，工人勿再問方向）

### 2.1 Tags（#1）
- **保留** B2-P08 前綴分組（有 label 很好）。
- **加上** Mockup 色系：依前綴映射 class（例：`t-ip`／`t-char`／`t-type`／`t-ctx`／warned），顏色只用 **現有 CSS 變數** `color-mix`（對照 Mockup `.rc-tag.t-*`，不要硬編 hex）。
- **每顆 chip 有 ×**：點 × 從 tags 字串移除該 tag（寫回既有 state／autosave 路徑，不另開 API）。
- **＋新增**：Mockup 式虛線 chip；點開可輸入後 Enter／確認加入；**不要**只剩底部一整條 raw comma input 當唯一操作（raw input 可收進「進階／完整字串」或保留次要，但主操作＝chip 增刪）。
- 警告角色一鍵新增規則庫（既有）**保留**，勿刪。

### 2.2 標題小標（#2）
- 來源＝`draft.sale_status`（必要時走 `normalizeSaleStatusLabel`／`mapSaleStatusToNestoryTagValue` 的**顯示用短標**）。
- 建議顯示文案（顧客可懂、對齊 tag 語感）：
  - 海外代購（約14天）→ **海外現貨**（或保留「海外代購」若老闆後改，預設短標 **海外現貨**）
  - 台灣現貨 → **台灣現貨**
  - 二手現貨 → **二手現貨**
  - 預購中 → **預購中**
- 位置：標題同一行後方小 chip／muted 小標（`rc-title` 旁），**不要**塞進站別狀態列搶戲。
- 無值則不顯示。

### 2.3 規格自動展開（#3）— **覆寫** B3-P06／舊註「never auto full cartesian」
- 當**至少一軸有軸值**且維度變更（加／刪軸值、加維度）時：**自動**呼叫既有 `expandAndMergeVariantRows` 路徑寫回 rows。
- **手填保護**仍要用 merge；若 `wouldDiscardHandFilled.length > 0`，**不得靜默丟資料**：維持既有二次確認（可改為 toast／inline arm，但不可默刪成本／圖）。
- UI：主按鈕「依軸值展開列」**改為自動**後，可改成狀態說明（「已依軸值展開」）或收成次要「重新展開」；**不要**再要求用戶多一步當主流程。
- 空軸值／單一款式可留空列：維持可 `+ 加入一列`。

### 2.4 軸類型 vs 軸值排版（#4）
- 規格類型（款式／尺寸…）與軸值 **換行分層**，不要類型 chip 與值擠同一視覺權重橫排。
- 類型可用「主操作感」樣式（例：接近 `vh-expand-primary` 的實心／強調 chip，但仍是標籤不是再一個展開鈕）；軸值維持較淡 chip。
- 只用 tokens；三主題自查。

### 2.5 列複製（#5）
- 每一展開列有「複製」：插入一列**深拷貝** optionValues／cost／圖／價格欄等表單欄位；新列視為可編輯（若有 id 策略，新列 id 清空讓 persist 當新列）。
- 上限仍守 `MAX_VARIANT_ROWS`；到頂誠實提示。
- 桌機／手機都要找得到（圖示或文字 mini）。

### 2.7 Shopify 真發布（#7）
- 語意澄清：老闆要「**可以成功發布到 Shopify**」＝**關閉** mock 安全模式。  
  `SHOPIFY_PUBLISH_MOCK=true`（預設）會假發布；設 **`false`** 才打真 API。
- **程式預設**（`.env.example`）可維持 true 防呆；**本機 `.env.local` + Vercel Production** 由老闆改 `SHOPIFY_PUBLISH_MOCK=false`。
- 前置：`SHOPIFY_CLIENT_ID`／`SECRET`／`STORE_DOMAIN` 已可用（A1）；缺憑證時 mock 分支仍會擋——要誠實錯誤，不要假裝成功卻沒進店。
- 本包**不**要求改 publish payload 邏輯（A14 已通）；以 env 切換＋狀態面板誠實顯示為主。

### 2.8 失敗／需修改卡（#8｜第二波）
- **「需修改」與「失敗」同大**：對齊字級／padding／高度；色相可不同（失敗 error、需修改 warn）。
- **紅字原因**（`failReasonSummary`／`.rc-fail-reason`，例：「缺少有效售價，無法產生價格帶_tag」）：
  從 header **下方橫幅**改到 **標題後方同一排**（可 wrap）。
- 桌機＋手機都適用；與 P04 手機第 1 排 slot 銜接。
- 優先 scope `.result-card`，避免全局 `.status` 誤傷設定頁等。
