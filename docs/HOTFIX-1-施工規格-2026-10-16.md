## 2. A：FAQ／規格改成「程式組 HTML」＋自動修壞格式

### A1. 新檔 `src/lib/contentGenerator/copyFormatRepair.ts`（純函式，不 import server 模組）

```ts
export const FAQ_PLACEHOLDER_HEADINGS: readonly string[]; // ["問題","問","題目","Q","Question"]
export const SPEC_PLACEHOLDER_LABELS: readonly string[];  // ["項目","規格名稱","名稱","規格項目"]

/** 模型輸出的 FAQ（新 Q/A 純文字，或舊 HTML）→ 標準 HTML。空字串進空字串出。 */
export function normalizeFaqOutput(raw: string): string;

/** 修正壞掉的 FAQ HTML；本來就正常的原樣回傳（逐字相同）。 */
export function repairFaqHtml(html: string): string;

/** 去掉每行開頭的佔位標籤（「項目:」「項目：」…）；其他行原樣。 */
export function repairSpecText(text: string): string;
```

**標準 FAQ HTML（唯一格式，和現有 DB 資料相同）**：每題
`<h3><strong>{問句}</strong></h3>\n<p>{答案}</p>`，題與題之間 `\n\n`。問句／答案要 escape `& < >`。

**`normalizeFaqOutput(raw)` 規則**：
1. `raw.trim()` 為空 → 回 `""`。
2. 含 `<h3` → 回 `repairFaqHtml(raw)`。
3. 否則當 Q/A 純文字解析：
   - 行首（去空白後）符合 `^(Q|Ｑ|問)\s*[:：]` → 新的一題，冒號後是問句。
   - 行首符合 `^(A|Ａ|答)\s*[:：]` → 這題的答案開始，冒號後是答案。
   - 其他非空行 → 接在目前「問句或答案」後面（中間加一個半形空格以外不加任何字；中文直接相接，不加空格）。**規則：上一段結尾和這行開頭都是 ASCII 英數才加一個空格，其他直接相接。**
   - 問句或答案為空的題目丟掉。最多保留前 5 題。
   - 一題都沒有 → 回 `""`（讓上層沿用既有「空值不覆蓋」的行為）。
4. 問句如果本身就是佔位字（`FAQ_PLACEHOLDER_HEADINGS` 之一，可帶冒號）→ 該題丟掉。

**`repairFaqHtml(html)` 規則**：
- 用 regex 掃 `<h3>\s*<strong>\s*(問題|問|題目|Q|Question)\s*[:：]?\s*</strong>\s*</h3>\s*<p>([\s\S]*?)</p>`（不分大小寫），換成 `<h3><strong>$2</strong></h3>`。這和 §3 的 SQL 是同一個轉換（SQL 版已在正式資料試算：18 筆全部修好、題數與答數一致）。
- 沒有命中 → **逐字原樣回傳**（不重新排版正常的 FAQ）。
- 換完如果還有某題 `<h3>` 後面沒有 `<p>` 答案，不要再動，原樣留著（只修這一種已知壞法）。

**`repairSpecText(text)` 規則**：逐行，行首（去空白後）符合 `^(項目|規格名稱|名稱|規格項目)\s*[:：]\s*` 就把這段標籤刪掉；刪完是空行就整行刪掉。其他行逐字不動，換行保持 `\n`。

## 3. B：修舊資料（只產 migration 檔，不執行）

新增 `supabase/migrations/20261016100000_hotfix1_repair_faq_spec_format.sql`，**內容逐字如下**（Claude 已用正式資料 SELECT 試算過，不要改 regex）：

```sql
-- HOTFIX-1: repair FAQ headings copied from the prompt placeholder ("問題")
-- and spec lines prefixed with the placeholder label ("項目:").
-- Data-only; idempotent (a second run matches nothing).
begin;

update public.product_drafts
set generated_faq_html = regexp_replace(
      generated_faq_html,
      '<h3>\s*<strong>\s*問題\s*[:：]?\s*</strong>\s*</h3>\s*<p>([^<]*)</p>',
      '<h3><strong>\1</strong></h3>',
      'g')
where generated_faq_html ~ '<strong>\s*問題\s*[:：]?\s*</strong>';

update public.product_drafts
set spec_text = regexp_replace(spec_text, '^[ \t]*項目[ \t]*[:：][ \t]*', '', 'gn')
where spec_text ~ '(^|\n)\s*項目\s*[:：]';

commit;
```

（Postgres 的 regex 不能混用貪婪/非貪婪，所以 SQL 用 `[^<]*`；TS 版用 `[\s\S]*?`，結果相同。）
