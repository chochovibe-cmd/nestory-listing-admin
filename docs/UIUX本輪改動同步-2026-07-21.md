## 2. 定案摘要（接手必知）

### 2.1 Tags（P01）
- 保留 B2-P08 前綴分組。
- `tagToneClass`：IP_／角色_／類型_／ctx 系／warned。
- chip × 刪、＋新增（Enter／確認／Esc）；raw 字串收 `<details>`。
- 不改 tag 規則引擎。

### 2.2 標題列（P02＋P06）
- `.rc-title-row`：標題 → **銷售小標**（`formatSaleStatusBadge`）→ **失敗紅字**（`failReasonSummary`）。
- 需修改／失敗同大：scoped `.result-card` 內 station chip 與 `.status.action|failed`。
- 舊 header 下紅條橫幅已移除。

### 2.3 手機結果卡（P04）— 僅 `max-width: 959`
| 排 | 內容 |
|---|---|
| 1 | 標題＋小標 |
| 2 | 左縮圖／右 chips |
| 3 | 左重生（文案站）／右售價 |
- 藏：checkbox、核准、×、▸；長按多選、左滑快捷保留。
- 桌機 chrome 維持。

### 2.4 規格（P03）
- 加／刪軸值 → `tryAutoExpandFromDimensions`（**無** useEffect 聽 dimensions，防 loop）。
- 手填會丟 → 二次確認，不默刪。
- 主 CTA＝「重新展開」；類型 `.vh-dim-type` 與軸值分層；列「複製」≤50。
- **覆寫** 舊註 never-auto cartesian → 見差異備忘 **43**。

### 2.5 Shopify（P05）
- `SHOPIFY_PUBLISH_MOCK !== "false"` → 模擬；僅明確 `false` 才真發。
- UI：「模擬中（不會建真實商品）」／「已接真店（真實發布）」。
- live 缺憑證 → `api_failed`，**禁止**再寫 `mock-product-id` 假成功。
- **老闆手動**：`.env.local` 與 Vercel 設 `false`＋三憑證＋重啟／Redeploy。

### 2.6 雙欄不重疊（P07）
- Grid：`minmax(0, 420px) minmax(0, 1fr)`。
- pane `min-width: 0`；panel `overflow-x: clip` + `overflow-y: visible`（保 sticky）。
- 表單控件／結果卡 `max-width: 100%`。

### 2.7 輸入縮圖（P08）— 對照 git 根因
| 狀態 | Commit | 行為 |
|---|---|---|
| 還好 | `ed342ce^` | `.pthumb-strip { flex-wrap: wrap }`；正方 64／96 |
| 壞 1 | `ed342ce` B2-P10 | nowrap + 橫滑；圖變大 |
| 壞 2 | `2cc900b` | × 挪左上擠規格圖 |
| 加劇 | `5f73952` P07 | `overflow-x: clip` 裁外側控件 |
| **現況** | `159721e` P08 | wrap 往下；72／96 正方；× 右上外側；規格圖**圖下 chip**；strip padding 避 clip；**站②橫滑未動** |
