【T65】發布紀錄批次 kind 篩選（R69）
────────
痛點：CSV／API 已入 publish_batches.kind，但 UI 無篩選。

指揮定案：
1. 在「批次」tab（batches）加 kind 篩選，選項至少：

   - Shopify API（對應 kind 實際字串，常見 shopify_api／shopify 等——**以 DB／型別為準**，修法清單寫死 map）
   - Showmore（showmore）
   - Matrixify（matrixify）

【T66】文案區欄位去向分組標示（R26 UI）
────────
痛點：審核時分不清欄位最後進 Shopify 哪裡；Fable 已有「規格中繼空但 D 段有內容」黃字（P2-82），本包只做**分組標示**。

指揮定案：
1. 站① 文案 tab（ResultCard copy panel）把欄位分成可見區塊，例如：
   - **上架描述**（或「商品介紹」）→ generated_description 等
   - **規格中繼**（若卡上有 spec／商品規格中繼欄）→ 標「給規格／D 段用」類短標
   - **FAQ** → generated_faq
   - 標題／賣點若在同 tab：可「標題與賣點」一組
2. 每組用既有 .rc-field-hdr／.rc-label 或輕量 section 標題（**中文、無 uppercase 回潮**）。
3. **不**改生成邏輯、不改欄位 key、不藏 Fable 黃字。
4. 資訊密度：只加小標，不加長篇說明（? 可選）。

驗：掃一眼知道描述／FAQ／規格中繼分組；手機不擠爆。
