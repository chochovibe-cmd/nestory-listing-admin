# Nestory 商品擷取（Chrome 擴充）

在淘寶／天貓／蝦皮／一般官網的**商品頁**按一下，把標題、價格、規格、圖片網址送到 Nestory，自動建成「待輸入」草稿。

> 這是給**非技術老闆**的安裝說明。一步一步做即可。  
> 若某一步卡住，那是說明書的問題，請回報「卡在第幾步、畫面上寫什麼」。

---

## 事前準備（在上架網站做）

1. 用瀏覽器登入你的 **Nestory 上架工具**（正式站或本機都可以）。
2. 打開 **設定** 頁。
3. 找到 **擷取 Token**（或「Chrome 擷取」相關區塊）。
4. 按 **產生**（或「重新產生」）。
5. **立刻複製**完整 token（長得像 `ncap_` 開頭的一串）。  
   只會完整顯示一次，關了視窗可能只剩遮罩。

本機開發時 API 網址通常是：`http://localhost:3000`  
正式站則是你的 Vercel 網址，例如：`https://你的專案.vercel.app`  
（**不要**在網址後面加 `/`。）

## 安裝擴充（開發者模式 · 未封裝）

### 步驟 1：打開擴充功能頁

1. 打開 **Google Chrome**。
2. 網址列貼上：`chrome://extensions`  
   然後按 Enter。

### 步驟 2：打開開發人員模式

1. 頁面**右上角**找到「**開發人員模式**」開關。
2. 把它**打開**（變藍色／啟用）。

### 步驟 3：載入本資料夾

1. 按「**載入未封裝項目**」（Load unpacked）。  
   → 會跳出選資料夾的視窗。
2. 選這個資料夾：  
   `（你的專案）/extension`  
   也就是跟 `manifest.json` **同一層**的 `extension` 資料夾。
3. 按「選取資料夾」。
4. 清單裡應出現 **「Nestory 商品擷取」**。

### 步驟 4：把圖示釘在工具列（建議）

1. 點 Chrome 工具列上的 **拼圖圖示**（擴充功能）。
2. 找到「Nestory 商品擷取」，按旁邊的 **圖釘** 釘選。  
   → 之後工具列會固定顯示圖示，方便一鍵擷取。

## 第一次設定（必做）

### 步驟 5：打開設定小視窗

1. 按工具列上的 **Nestory 圖示**。  
   → 應跳出小視窗（設定畫面）。  
   若沒有跳出、卻直接顯示紅點：到 `chrome://extensions` 找到本擴充，按「**詳細資料**」，或重新載入擴充後再點一次圖示。

### 步驟 6：填兩欄並儲存

1. **API 網址**：貼你的 Nestory 網址（見上方「事前準備」）。
2. **擷取 Token**：貼 `ncap_` 那一串。
3. 按 **「儲存設定」**。  
   → **權限視窗會在按下「儲存設定」時跳出**（不是之後才跳）。

### 步驟 7：授權視窗按「允許」（重要）

1. 按完「儲存設定」後，Chrome 可能立刻跳出「**要允許 Nestory 商品擷取 讀取與變更以下網站的資料嗎？**」之類的視窗。
2. 請按 **允許**。  
   → 這是為了讓擴充能把資料**送到你的 Nestory**（不是亂連別的站）。
3. 小視窗應顯示類似：「已儲存。現在開商品頁…」

若你按「拒絕」，儲存會失敗，畫面上會用白話說明原因。請重新按「儲存設定」並改按「允許」。

## 日常使用：一鍵擷取

1. 用 Chrome **登入**淘寶／天貓／蝦皮（若商品需要登入才看得到價）。
2. 打開**單一商品頁**（網址通常含商品 id，不是搜尋列表）。
3. 按工具列 **Nestory 圖示**一下。  
   → **不會**再跳設定窗，而是直接擷取。
4. 圖示上可能出現：
   - **綠 ✓**：成功新建草稿  
   - **黃／數字**：該網址草稿已存在（不重複建）  
   - **紅 !**：失敗（看設定小窗的「最近結果」）
5. 要看文字結果：在設定小窗看「**最近結果**」一行。  
   成功範例：`已建草稿：標題…×圖 8×款式 3`  
6. 回到 Nestory **草稿佇列**，應能看到新草稿；點進去表單會預填（抓到的欄位）。

### 一般官網（非淘寶／蝦皮）

用工具列圖示按一下擷取即可（靠「按了才動」的暫存權限）。  
**連到 Nestory 的授權**只在「儲存設定」時處理一次；若紅字提示尚未允許連線，回到設定再存一次並按允許。

### 想改 API 網址或 Token

1. 打開設定小窗，任選一種：
   - 到 `chrome://extensions` → 找到 Nestory → 按「**詳細資料**」→「**擴充功能選項**」；或  
   - 在拼圖選單對 Nestory 按右鍵 →「**選項**」；或  
   - 若小窗已開著，可按「**固定開啟此設定頁**」。
2. 改欄位 → 再按「儲存設定」→ 若跳出授權視窗請按「**允許**」。
3. 改完可按「**改回：按圖示＝直接擷取**」（之後點工具列圖示就會直接擷取，不再先開設定）。

## 抓不到某些欄位？

擴充**不猜**。沒抓到的會省略，並在送出資料裡標記警告。  
請在 Nestory 草稿上**手動補**售價、圖、規格。淘寶大改版時可能暫時變弱，回報「網址＋哪一欄是空的」即可（工程師只改 `extension/lib/selectors.js`）。

---

## 安全說明（白話）

- **不會**幫你自動登入、**不會**偷密碼。
- **只有你按圖示**才會讀當前商品頁。
- Token **只能新建草稿**，不能刪資料、不能讀你整站。
- Token 外洩：到 Nestory 設定 **重設 token**，舊的立刻失效。

## 給工程師

- 目錄獨立於 `src/`，**不進** Next.js build。
- 契約：`POST /api/import/product-page`，`Authorization: Bearer ncap_…`，body 對齊 `src/lib/import/captureTypes.ts`。
- 選擇器唯一真相：`lib/selectors.js`。
- 驗證：`pnpm run verify:cap2`（linkedom + 樣本 HTML，不連真站）。
- MV3 對 API 的 `fetch` 需目標 origin 的 host permission；
  **`permissions.request` 只能在 popup 的「儲存設定」click 手勢裡呼叫**（不可經 background message）。
  background 僅 `permissions.contains` 檢查。
