# 詳情圖品牌風格（來源：www.chochonest.com Horizon 主題匯出 2026-06-29，老闆 2026-07-19 提供）

> 詳情圖掛在商店前台,風格以「網站主題」為準,不是後台工具的 globals.css。
> 以下值直接抄自主題 settings_data.json 的 scheme-1（主場景）。

## 色彩
| 用途 | 值 |
|---|---|
| 底色 | `#faf8f3`（奶油白,全圖底） |
| 標題字 | `#2a2a2a` |
| 內文字 | `#4a4a4a` |
| 強調/按鈕帶 | 黑 `#2a2a2a`~`#000000` 底＋白字 |
| 邊框/分隔線 | `#0000000f`（極淡）,輸入框級 `#dfdfdf` |
| 次要底 | scheme-2 `#f5f3f0`（區塊交錯用） |

## 字體
- 主題原字:標題 Cormorant（襯線）、內文/副標 Inter
- 中文對應（設計轉譯,渲染機需已安裝或 webfont 內嵌）:
  標題 → Noto Serif TC / 思源宋體（呼應 Cormorant 襯線氣質）
  內文 → Noto Sans TC / 微軟正黑
- 數字與英文可直接用 Cormorant（標題）/ Inter（內文）

## 氣質
極簡、留白多、細線分隔、黑白灰＋奶油白,不用彩色大色塊、不用電商紅黃促銷感。
賣點/規格區塊用細邊框卡片或細線分隔,不用粗底色條。
