════════════════════════════════════
問題
════════════════════════════════════
輸入區多層都是「同色底 + 1px solid var(--border)」→
大框套小框，眼睛分不出層級。

════════════════════════════════════
定案原則
════════════════════════════════════
1. 同一層只用一種區隔：換底色 **或** 邊框，不要兩者都搶
2. 相鄰層交替：淺 → 深 → 淺（或反）
3. 箭頭 ▾／▸ 縮小、淡化（opacity ~0.5），不跟標題搶

建議節奏（tokens）：

/* L1 外層面板 — 保留框 */
.panel.workspace-input-panel {
  background: var(--surface);
  /* border 沿用既有 .panel，勿加第二層框 */
}

/* L2 收合區 — 用底色，去掉重框 */
.workspace-input-panel .adv-section {
  background: var(--surface2);
  border: none;                 /* 或 1px solid transparent / border-soft 極淡二選一；定案：無框 */
  border-radius: var(--radius-m);
  /* padding 可微調；勿大改間距系統 */
  box-shadow: none;
}
.workspace-input-panel .adv-section-body {
  /* 維持可讀內距即可 */
}

/* L2 箭頭低調 */
.workspace-input-panel .adv-section-title > span:first-child {
  opacity: 0.5;
  font-weight: 600;
  font-size: 11px; /* 可略小於標題；勿小於 10 */
}

/* L3 內卡 — 回到 surface + 淡框 */
.workspace-input-panel .source-card,
.workspace-input-panel .tone-card {
  background: var(--surface);
  border-color: var(--border-soft); /* 比 --border 淡；dashed 可保留 shot 卡 */
}

/* 文案設定內的 copy-options-group：避免又變「第四層重框」 */
.workspace-input-panel .copy-options-group {
  border-color: var(--border-soft);
  background: color-mix(in srgb, var(--surface) 70%, var(--surface2));
  /* 或 border: none + 僅靠 L2 底色差 — 擇較清爽者，三主題都要看 */
}

.tone-card 選中態（.sel / .active）維持 accent 框，不要砍選取回饋。
.source-card--shot:hover／dragover 的 accent 可留。

════════════════════════════════════
實作步驟
════════════════════════════════════
1. 只在 .workspace-input-panel 下加／覆寫，寫在 globals 合適位置並註解 UX-B3-P05
2. 不要改 SettingsPanel 用的全域 .adv-section 預設（除非確認設定也要同一套——本包不要）
3. 桌機 + 手機（≤959）各看一次新增頁輸入區
4. 三主題 dark／nordic／kitty：surface／surface2 對比要還在（nordic 淺色勿洗成一片）
