痛點 R68：表格模式只有精簡 7 欄，對帳 CSV 不夠；多款式列看不出 Matrixify 語意。

指揮定案：
1. **表格模式**改為渲染 **完整欄位**（至少 Matrixify 下列順序，作表頭）：

   Command, Handle, Title, Body HTML, Vendor, Type, Tags, Published, Status,
   SEO Title, SEO Description, Option1 Name, Option1 Value, Option2 Name,
   Option2 Value, Option3 Name, Option3 Value, Variant SKU, Variant Price,
   Variant Cost, Variant Inventory Tracker, Variant Inventory Qty,
   Variant Inventory Policy, Variant Requires Shipping, Variant Image,
   Image Src, Image Position, Image Alt Text

2. 資料來源：優先用 **buildMatrixifyRows（或等價已產出之完整列物件）**；
   不要再只用 PreflightItem 那 7 個 display 欄硬撐完整表。
3. **橫向捲動**：`.export-pf-table-wrap`（或等價）overflow-x: auto；表不撐爆 modal 寬。
4. **空格照實**：同 Handle 後續列 Title/Body/Vendor/Tags/SEO/主圖欄**留白是刻意的**——
   **禁止** UI 自動填上一列的值。
5. 多 variant：款式列在前、圖片列在後（資料已是此序則照渲染）。
6. **Showmore**：若表格模式共用元件，首列有名後列留白同理照實。
7. 條列摘要模式可保留（精簡售價／燈號）；表格＝對帳用全欄。
8. 手機：modal 已 bottom sheet；表可橫滑；觸控可捲。

驗：Matrixify 預覽表格欄數≈完整 CSV；多款式商品見多列＋留白；橫向可捲；不改實際下載 CSV 內容（與表一致即可）。
