## 2. 做了什麼

### selectors.js（主改檔）

taobao **與** tmall 都補 ssr2025。tmall 是差集：`skuRoot` 若不寫進 tmall，merge 會整包蓋掉 taobao 的新 id。

新增／提前的選擇器：

| key | 新增（置前） |
|---|---|
| skuRoot | `#SkuPanel_tbpcDetail_ssr2025`、`[id^='SkuPanel_'][id*='ssr2025']`、`#skuOptionsArea` |
| skuAxis | `[class*='skuItem--']`、`[class*='SkuItem--']`（在寬鬆 `skuItem` / `dl.tb-prop` 之前） |
| skuAxisLabel | `[class*='ItemLabel--']` |
| skuValue | `[class*='valueItem--']`、`[class*='ValueItem--']` |
| skuValueThumb | `[class*='valueItemImg']` |
| paramsTable | `[class*='ParamsInfoItem--']`、`[class*='generalParamsInfoItem--']`、`[class*='emphasisParamsInfoItem--']` |
| tmall title | `[class*='MainTitle']`、`[class*='mainTitle']` |
| tmall originalPrice / listPrice | `[class*='subPrice']` |
| tmall promoPrice / price | `[class*='highlightPrice'] [class*='text']` |

從 skuAxis 移除 `[class*='valueItem']`（那是值不是軸）。舊 `.tb-sku` / `#J_isku` / `dl.tb-prop` / `li a` 仍保留，舊 fixture 繼續走這條。

### adapters/taobao.js（最小接線，不是 JSON fallback）

既有 `extractSkuFromRoot` **沒有讀 `S.skuAxis`**，只寫死 `dl.tb-prop, [class*='skuItem']`。只改 selectors.js 無法避開 `skuItemClipX`。

因此：

1. 軸改為對 `S.skuAxis` **first-match-wins**（與 skuValue 同一慣例）。
2. 值文案優先 `valueItemText` 的 `title`，避免「推薦」角標黏在規格名上。
3. 軸名 `數量` / `数量` 略過（數量選擇器在 skuWrapper 裡，但不是 skuItem--）。
4. `emphasisParams*` 列：subtitle = 標籤、title = 值（與 generalParams 相反）。

**沒有**改 `flattenSku` / `omitUniformVariantPrices` / cartesian。

### fixture + verifier

- 新增精簡 `scripts/fixtures/tmall-ssr2025-sku.html`（面板 + 參數，不是 605KB 存檔）。
- `scripts/verify-cap2.mjs`：新 fixture 必須 ≥1 軸、多個值、params ≥1，且強調區不得 key/value 對調；舊 taobao fixture 全數繼續 PASS。
