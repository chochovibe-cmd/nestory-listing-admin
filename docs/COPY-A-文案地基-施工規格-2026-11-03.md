## 0. 一句話

現在的工具其實已經是「兩段式」：便宜模型（Product Brief，gpt-4o-mini）先整理事實，再由 gpt-4o 寫全部文案。問題在於：
1. **錢看不到**：只記了 Writer 的錢，看圖（Vision）和 Brief 都沒記，所以算不出一件真正花多少。
2. **壞了不會叫**：10-20 缺金鑰、10-22 OpenAI 沒錢，都是事後才發現。
3. **換模型不安全**：4g 之後只要改環境變數就能換模型，但 Brief 的 JSON 解析、推理型模型、費用估算都只認得 OpenAI。
4. **寫手太忙、證據太薄**：gpt-4o 一次寫 7 欄（含 SEO），沒設 temperature（預設 1.0，起伏大）；款式摘要被截斷、4a 抓到的評價沒送進去、證據薄時照樣灌水。

所以拆兩包：

| 包 | 一句話 | 動到的東西 | 預估 |
|---|---|---|---|
| **COPY-A1** 看得到錢、壞了會叫、可換模型 | 頁面頂端紅色提醒；每一步記成本；OpenRouter 回報實際花費；Writer temperature／推理參數可用環境變數調；Brief 解析容錯；重生視窗語氣預設改對 | 不改文案內容（環境變數沒設＝跟現在一樣） | 1–2 天 |
| **COPY-A2** 三段式＋證據變厚 | 程式整理資料（款式不截斷、評價、證據量）→ 便宜模型「看懂商品」出事實表 → 好模型只寫 5 樣 → 程式檢查＋SEO 套模板 | 潮巢導購版的生成流程 | 3–4 天＋盲測 |

**AI 呼叫次數不增加**：看圖 1 次＋看懂商品 1 次＋寫文案 1 次，跟現在一樣。

**預算**：每件 AI 總成本上限 NT$2、平均目標 NT$1（1 美元以 32 台幣計）。A1 先記帳、超過就在卡片提醒；A2 不加呼叫，所以不會因為這包變貴。寫手換成誰，由 §4 盲測決定。

### 2.1 新檔 `src/lib/ai/aiCost.ts`（照抄）

```ts
/**
 * COPY-A1: per-stage AI cost bookkeeping for one product generation.
 * OpenRouter reports the real charge (usage.cost, USD) when asked; otherwise we fall back
 * to the list-price estimate in providers/copy.ts. Display/warning only — never blocks a run.
 */
import { estimateCopyCostUsd, type RawUsage } from "@/lib/providers/copy";

export const AI_COST_TWD_PER_USD = 32;
/** 每件 AI 總成本上限（老闆 10-28）。 */
export const AI_COST_CAP_TWD = 2;
/** 每件平均目標（只顯示，不擋）。 */
export const AI_COST_TARGET_TWD = 1;

export type AiStage = "vision" | "understand" | "writer";
export type AiVia = "openrouter" | "openai" | "none";

export type AiStageCost = {
  stage: AiStage;
  model: string;
  via: AiVia;
  inputTokens: number;
  outputTokens: number;
  costUsd: number;
  /** true = OpenRouter's own usage.cost; false = our list-price estimate. */
  reported: boolean;
};

export type AiCostRecord = {
  version: "copy-a-cost-1";
  stages: AiStageCost[];
  totalUsd: number;
  totalTwd: number;
  capTwd: number;
  overCap: boolean;
};

const STAGE_LABEL: Record<AiStage, string> = { vision: "看圖", understand: "看懂商品", writer: "寫文案" };

function finiteNonNeg(value: unknown): number {
  const n = Number(value);
  return Number.isFinite(n) && n > 0 ? n : 0;
}

export function usdToTwd(usd: number): number {
  return Math.round(usd * AI_COST_TWD_PER_USD * 100) / 100;
}

/** Reported (OpenRouter) cost wins; otherwise list-price estimate. */
export function stageCost(input: {
  stage: AiStage;
  model: string;
  via: AiVia;
  usage: RawUsage;
  reportedCostUsd?: number | null;
}): AiStageCost {
  const reported = typeof input.reportedCostUsd === "number" && Number.isFinite(input.reportedCostUsd) && input.reportedCostUsd >= 0;
  return {
    stage: input.stage,
    model: input.model,
    via: input.via,
    inputTokens: finiteNonNeg(input.usage.inputTokens) + finiteNonNeg(input.usage.cachedInputTokens),
    outputTokens: finiteNonNeg(input.usage.outputTokens),
    costUsd: reported
      ? Math.round((input.reportedCostUsd as number) * 1_000_000) / 1_000_000
      : estimateCopyCostUsd(input.model, input.usage),
    reported,
  };
}

export function buildCostRecord(stages: AiStageCost[]): AiCostRecord {
  const totalUsd = Math.round(stages.reduce((sum, s) => sum + finiteNonNeg(s.costUsd), 0) * 1_000_000) / 1_000_000;
  const totalTwd = usdToTwd(totalUsd);
  return { version: "copy-a-cost-1", stages, totalUsd, totalTwd, capTwd: AI_COST_CAP_TWD, overCap: totalTwd > AI_COST_CAP_TWD };
}

/** Yellow card warning when one product cost more than the cap; null otherwise. */
export function costOverCapWarning(record: AiCostRecord): string | null {
  if (!record.overCap) return null;
  const parts = record.stages
    .filter((s) => s.costUsd > 0)
    .map((s) => `${STAGE_LABEL[s.stage]} NT$${usdToTwd(s.costUsd).toFixed(2)}`);
  return `💸 這件 AI 花費約 NT$${record.totalTwd.toFixed(2)}，超過每件上限 NT$${AI_COST_CAP_TWD}（${parts.join("／")}）`;
}

/** Vision usage relayed by the browser (analyze-images → /api/generate). Bookkeeping only; clamp hard. */
export function sanitizeRelayedStageCost(value: unknown): AiStageCost | null {
  if (!value || typeof value !== "object") return null;
  const v = value as Record<string, unknown>;
  if (v.stage !== "vision" || typeof v.model !== "string" || !v.model.trim()) return null;
  const via: AiVia = v.via === "openrouter" || v.via === "openai" ? v.via : "none";
  const costUsd = Math.min(finiteNonNeg(v.costUsd), 1);
  return {
    stage: "vision",
    model: v.model.trim().slice(0, 80),
    via,
    inputTokens: Math.min(Math.round(finiteNonNeg(v.inputTokens)), 2_000_000),
    outputTokens: Math.min(Math.round(finiteNonNeg(v.outputTokens)), 200_000),
    costUsd: Math.round(costUsd * 1_000_000) / 1_000_000,
    reported: v.reported === true,
  };
}
```

### 2.2 `src/lib/providers/textAiEndpoint.ts`：加兩個函式（照抄，原有三個函式不動）

```ts
const REASONING_EFFORTS = ["minimal", "low", "medium", "high"] as const;

/**
 * COPY-A1: extra request-body fields per route. OpenRouter: always ask for usage.cost
 * (real charge in USD); add reasoning effort only when TEXT_AI_REASONING_EFFORT is set
 * (reasoning tokens bill as output). OpenAI direct: nothing extra (unchanged behaviour).
 */
export function textAiExtraBody(endpoint: TextAiEndpoint): Record<string, unknown> {
  if (endpoint.via !== "openrouter") return {};
  const extra: Record<string, unknown> = { usage: { include: true } };
  const effort = process.env.TEXT_AI_REASONING_EFFORT?.trim().toLowerCase();
  if (effort && (REASONING_EFFORTS as readonly string[]).includes(effort)) {
    extra.reasoning = { effort };
  }
  return extra;
}

/** Normalised usage from a chat/completions payload; reportedCostUsd only when the route reported it. */
export function readChatUsage(payload: unknown): {
  inputTokens: number;
  outputTokens: number;
  cachedInputTokens: number;
  cacheCreationTokens: number;
  reportedCostUsd: number | null;
} {
  const u = (payload as { usage?: Record<string, unknown> } | null)?.usage ?? {};
  const details = (u.prompt_tokens_details ?? {}) as Record<string, unknown>;
  const cached = Number(details.cached_tokens) || 0;
  const cost = Number(u.cost);
  return {
    inputTokens: Math.max((Number(u.prompt_tokens) || 0) - cached, 0),
    outputTokens: Number(u.completion_tokens) || 0,
    cachedInputTokens: cached,
    cacheCreationTokens: 0,
    reportedCostUsd: u.cost !== undefined && u.cost !== null && Number.isFinite(cost) && cost >= 0 ? cost : null,
  };
}
```

```ts
/**
 * COPY-A1: one red line at the top of every page when text AI is down or about to run dry.
 * 10-20 (missing key) and 10-22 (OpenAI out of credit) were only noticed days later.
 */
import { humanizeAiError } from "@/lib/drafts/aiErrorMessage";
import { AI_COST_TWD_PER_USD } from "./aiCost";

/** 低於這個餘額就提醒（約 60–100 件商品的量）。 */
export const AI_HEALTH_LOW_BALANCE_USD = 2;
/** 失敗多久以內才提醒；之後有成功的生成就自動消失。 */
export const AI_HEALTH_FAILURE_WINDOW_HOURS = 48;

export type AiHealthLastRun = { status: "completed" | "failed"; error: string | null; finishedAt: string | null };

export type AiHealthInput = {
  hasTextAiKey: boolean;
  lastRun: AiHealthLastRun | null;
  openRouterRemainingUsd: number | null;
  now: Date;
};

/** Provider-side failure (auth, credit, rate limit, 5xx, missing key) — not timeouts or network blips. */
export function isAiProviderFailure(message: string | null | undefined): boolean {
  const text = (message ?? "").trim();
  if (!text) return false;
  return /failed \((?:401|402|403|429|5\d\d)\)|not configured|insufficient_quota/i.test(text);
}

function taipeiTime(iso: string | null): string {
  if (!iso) return "";
  const date = new Date(iso);
  if (Number.isNaN(date.getTime())) return "";
  return new Intl.DateTimeFormat("zh-TW", {
    timeZone: "Asia/Taipei", month: "2-digit", day: "2-digit", hour: "2-digit", minute: "2-digit", hour12: false,
  }).format(date);
}

/** Banner text, or null when everything is fine. Priority: no key > recent failure > low balance. */
export function aiHealthBannerText(input: AiHealthInput): string | null {
  if (!input.hasTextAiKey) {
    return "AI 文案停擺：伺服器沒有設定 OPENROUTER_API_KEY（或 OPENAI_API_KEY），新商品產不出文案。";
  }
  const run = input.lastRun;
  if (run && run.status === "failed" && isAiProviderFailure(run.error)) {
    const finished = run.finishedAt ? new Date(run.finishedAt).getTime() : NaN;
    const ageHours = Number.isFinite(finished) ? (input.now.getTime() - finished) / 3_600_000 : 0;
    if (ageHours <= AI_HEALTH_FAILURE_WINDOW_HOURS) {
      const reason = humanizeAiError(run.error).replace(/\s+/g, " ").slice(0, 80);
      const when = taipeiTime(run.finishedAt);
      return `AI 文案生成失敗${when ? `（${when}）` : ""}：${reason}。修好前新商品產不出文案。`;
    }
  }
  const remaining = input.openRouterRemainingUsd;
  if (typeof remaining === "number" && Number.isFinite(remaining) && remaining < AI_HEALTH_LOW_BALANCE_USD) {
    const twd = Math.max(0, Math.round(remaining * AI_COST_TWD_PER_USD));
    return `OpenRouter 餘額剩 US$${Math.max(0, remaining).toFixed(2)}（約 NT$${twd}），快用完了：請到 OpenRouter 儲值。`;
  }
  return null;
}

/** GET /api/v1/credits → total_credits - total_usage (USD). Any problem → null (no balance line). */
export async function fetchOpenRouterRemainingUsd(apiKey: string): Promise<number | null> {
  try {
    const response = await fetch("https://openrouter.ai/api/v1/credits", {
      headers: { Authorization: `Bearer ${apiKey}` },
      signal: AbortSignal.timeout(3000),
      next: { revalidate: 600 },
    } as RequestInit);
    if (!response.ok) return null;
    const payload = (await response.json()) as { data?: { total_credits?: unknown; total_usage?: unknown } };
    const credits = Number(payload?.data?.total_credits);
    const usage = Number(payload?.data?.total_usage);
    if (!Number.isFinite(credits) || !Number.isFinite(usage)) return null;
    return Math.round((credits - usage) * 100) / 100;
  } catch {
    return null;
  }
}
```

```tsx
// COPY-A1: red line under EnvironmentBanner. Server component; never throws (a broken

export async function AiHealthBanner() {

    const endpoint = resolveTextAiEndpoint();
    const service = createServiceSupabaseClient();
    const { data } = await service
      .from("generation_runs")
      .select("status,error_message,completed_at")
      .in("status", ["completed", "failed"])
      .order("completed_at", { ascending: false, nullsFirst: false })
      .limit(1);

  } catch {

  }
}
```

### 3.2 ① 程式整理資料 `evidence.ts`

**款式結構** `buildVariantStructure(rows)`：輸入 `product_variants` 的 `option1_value／option2_value／option3_value`（照現在 `buildStoredVariantSummary` 讀的那幾列）。
- 輸出 `{ count, axes: string[][], text }`；`axes[i]` 是第 i 軸不重複的值（照出現順序）。
- `text` 格式（照抄）：
  ```
  款式共 35 款
  - 第 1 軸（7 種）：睡衣小新、動感超人、…
  - 第 2 軸（2 種）：單拍、禮盒
  ```
  只有一軸時不寫「第 1 軸」改寫 `- 款式（7 種）：…`。每軸最多列 60 個值，超過寫「…等 N 種」；整段上限 2,500 字。**不再串成一行截斷**。
- Brief 的款式輸入上限從 1,200 字改成 2,500 字（`productBrief.ts` `evidenceMessage`）。

**買家評價** `buildReviewEvidence(reviews: SourceReviews | null)`：讀 `readSourceReviews(draft.raw_capture)`（`/api/generate` 查草稿時多 select `raw_capture`）。沒有就回空字串。格式（照抄）：
```
買家評價（淘寶原頁；只能用來理解商品，不可寫成「買家說」、不可引用原句）
- 評價數：2000+；好評率：99%
- 印象標籤：尺寸剛好(23)、做工精細(12)
- 短評：做工很好比想像中小一點（款式：小新睡衣款）
- 店鋪訊號：回頭客 1000+
```
沒有的那一行就不寫（評價數、好評率只有一個時只寫那一個）。印象標籤次數是 null 就只寫字（`做工精細`）。短評最多 5 則、每則 120 字，有購買款式才加「（款式：…）」。

**證據量** `scoreEvidence({ factCount, specCount, visionTextChars, hasReviews, noteChars })` → `{ score, level }`（照抄公式）：
```
score = min(specCount, 6) × 2 + min(factCount, 8) + (hasReviews ? 2 : 0) + (visionTextChars >= 80 ? 2 : 0) + (noteChars >= 20 ? 1 : 0)
level = score < 6 ? "thin" : score >= 14 ? "rich" : "normal"
```
- `factCount`＝事實表 `confirmedFacts` 數、`specCount`＝`specLines` 數（② 跑完才算；② 失敗退回保守版＝直接算 thin）。
- `visionTextChars`＝`image_description` 裡【圖上文字】那段的字數（寫「（無）」算 0）。

| `number_not_in_evidence` | 文案裡「數字＋單位」（cm、mm、公分、ml、毫升、g、克、kg、公斤、W、V、mAh、吋、寸、款、入、個、張、小時、分鐘）的數字，在證據全文（賣家標題＋款式結構＋備註＋圖片辨識＋事實表）找不到 | `【文案檢查】文案寫了「35款」，但資料裡找不到 35：請確認` |
| `voltage_missing` | 事實表 `requiresVoltage=true` 且 `voltage` 空 | `【文案檢查】⚡ 插電商品沒有電壓資料：上架前確認台灣 110V 能不能用` |
| `voltage_220` | `taiwanRisks` 有 220V，但正文和 FAQ 都沒提到 220V／110V | `【文案檢查】⚡ 這件是 220V，文案沒有提醒台灣不能直接用` |
| `empty_field` | 5 樣裡有空的 | `【文案檢查】「為什麼選它」是空的` |

同一個 code 只出一條（多個詞合在同一條）。

數字比對的寫法：只比「數字本身」（`5.8 公分` 和證據裡的 `5.8cm` 算同一個），在證據全文裡要以獨立數字出現（`35` 不能被 `1350` 裡的 35 算到）。證據本身是簡體也沒關係，只比數字。

**證據薄提醒**（不屬於 checkCopy，由 route 加）：`level === "thin"` 時加一條（照抄）：
`📉 資料偏少：這件只找到 {factCount + specCount} 條可用事實，文案已自動寫短。想寫完整，先在備註補尺寸／材質／玩法，或在圖片區勾「文案參考」再重新生成。`
