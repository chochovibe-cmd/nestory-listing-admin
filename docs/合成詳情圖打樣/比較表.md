## 2. 總覽比稿

| 維度 | 路線 A（模板合成） | 路線 B（gpt-image-1 medium · 1024×1536） |
|---|---|---|
| **清晰度（字）** | 滿分：系統字體點陣清楚、可選取級可讀 | 敗：中文大面積亂碼／近亂碼；英文與少數數字偶可讀 |
| **風格** | 穩定潮巢氣質（nordic／dark 可切）；像「官網說明卡」 | 氛圍海報感強；B2 商品照較真，但版面像「AI 海報」非資訊卡 |
| **成本（估）** | **$0** | 成功 4 張 × $0.07 ≈ **$0.28**；另有 1 次 safety 失敗（是否計費視帳號，保守合計 **≤$0.35**，在 $0.40 上限內） |
| **產出時間** | 約 **3–5 秒／張**（本機 Chrome） | 約 **25–27 秒／張**（API） |
| **資訊正確性** | **100% 抄草稿**（見下表） | **數字會被改寫**；中文不可信賴（見 §3） |
| **長圖能力** | **1080 寬 × 內容高**（真長圖） | 官方上限直式 **1024×1536**，非無限捲詳情 |
| **其他風險** | 需本機 Chrome；版型要維護 | IP／角色 prompt 易觸 **safety**（Razer×寶可夢 B1 首發被拒）；商品外觀 B1 易「腦補」 |

### 建議（給老闆挑）

| 選項 | 何時選 |
|---|---|
| **A** | 要正確規格、正確中文、可量產統一版型、近零成本 |
| **B** | 只要氛圍海報、可接受不可讀字與錯數字——**本打樣顯示不適合當「詳情資訊圖」** |
| **混合（規格書預期落點）** | **文字／規格／賣點走 A**；若需要可把 B 當「頭圖氛圍素材」另用，**禁止**把 B 圖上的規格當真相 |

**本包結論（工人）**：比稿證據強烈支持 **A 或 A 為主的混合**；B 單獨上路會在「規格數字被改」這一欄直接出局。
