> 1. 每個 session 開始：讀本清單 → 跟使用者確認本次要做哪 3–5 項（一次不要超過 5 項）

### 目錄外類型盤點 SQL（P6｜貼 Supabase SQL Editor 即用，唯讀）

> **用途**：定期看「系統偵測到、但沒產出正式 `類型_` tag」的商品類型字，方便收編進固定目錄或 alias。  
> **零 migration**：資料本來就在 `product_drafts.product_type`／`warnings`／tags。  
> **說明**：下列「有 product_type、tags 裡卻沒有任何 `類型_`」的列，多半是目錄外（或真空但欄位有殘值）。  
> 收編後舊草稿要**重生**才會補上正式 tag。

```sql
-- 1) 依 product_type 分組：有類型字、但 shopify_tags／tags 都沒有 類型_ 開頭
select
  nullif(trim(product_type), '') as product_type,
  count(*) as draft_count,
  max(created_at) as last_seen,
  min(created_at) as first_seen
from public.product_drafts
where product_type is not null
  and trim(product_type) <> ''
  and coalesce(status, '') <> 'archived'
  and not exists (
    select 1
    from unnest(
      coalesce(shopify_tags, array[]::text[])
      || coalesce(tags, array[]::text[])
    ) as t(tag)
    where tag like '類型_%'
  )
group by 1
order by draft_count desc, last_seen desc;

-- 2) 用警告文案撈（含 P6 新文案「待收編類型」與舊文案「不在 Tags V2」）
select
  w as warning_text,
  count(*) as hit_count,
  max(d.created_at) as last_seen
from public.product_drafts d
cross join lateral unnest(coalesce(d.warnings, array[]::text[])) as w
where w like '%待收編類型%'
   or w like '%不在 Tags V2 固定類型中%'
group by 1
order by hit_count desc, last_seen desc
limit 50;

-- 3) 抽樣：最近 20 筆待收編草稿（好點開對帳）
select
  id,
  title_zh,
  product_type,
  status,
  pipeline_stage,
  created_at
from public.product_drafts
where product_type is not null
  and trim(product_type) <> ''
  and coalesce(status, '') <> 'archived'
  and not exists (
    select 1
    from unnest(
      coalesce(shopify_tags, array[]::text[])
      || coalesce(tags, array[]::text[])
    ) as t(tag)
    where tag like '類型_%'
  )
order by created_at desc
limit 20;
```
