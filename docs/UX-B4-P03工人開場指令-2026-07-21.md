本包三件
════════════════════════════════════

【① 自動依軸值展開】
1. 當 dimensions 軸值變更（addAxisValue／dropAxisValue／addDimension 後若已有值、removeDimension 後）且 canExpandFromDimensions：
   → 呼叫與 expandFromAxisValues 相同核心（expandAndMergeVariantRows + withInheritedProductCost）。
2. 若 wouldDiscardHandFilled.length > 0：
   - **禁止**自動套用丟資料
   - 顯示既有二次確認 arm（或明確「軸值已變更，重新展開會影響 N 筆手填 — 確認」）
3. 主 CTA：
   - 有軸值且已同步：可改文案「已依軸值展開」disabled／ghost 狀態說明
   - 或保留「重新展開」次要按鈕
   - **主流程不得再強迫多按一次才出列**
4. 單一款式無軸值：仍可 + 加入一列；empty 文案更新（拿掉「再按依軸值展開列」教學句）。
5. 注意 useEffect 迴圈：dimensions 變更 → expand → setRows 不要回寫 dimensions 造成無限 loop。
6. 笛卡尔 >50 仍走 CARTESIAN_CLAMP_WARNING。

【② 類型 vs 軸值排版】
1. 規格類型（款式／尺寸…）與軸值 **分行**：類型一列（或獨立強調 chip），軸值＋「加軸值」下一列。
2. 類型視覺：比軸值更「主」——可接近 primary 按鈕質感（實心／較重 border），但不是第二個展開鈕。
3. 軸值維持淡 chip + ×。
4. 手機（isNarrow）同樣不擠；觸控 ≥44px。

【③ 列複製編輯】
1. 每列 actions 加「複製」：
   - 深拷貝 optionValues、cost、imageId、sku、qty、sellPrice、compareAt、priceLocked 等表單欄
   - 插入 index+1；若有 row id 欄則新列清空 id（當新列 persist）
2. rows.length >= MAX_VARIANT_ROWS → disabled + 誠實提示
3. 複製後使用者可立即改軸值／成本（即「複製再編輯」）
4. 桌機＋手機都可見（mini 文字或 icon+aria-label）
