【T20】Ctrl+V／貼上圖片 → 截圖辨識或主圖上傳
────────
老闆痛點（回饋 1）：截圖辨識只能選檔，不能貼上。

1. **截圖辨識區**（WorkspaceInputPanel 標題旁 📷／規格截圖）：

   - clipboardData.files 或 items 裡 image/* → 走既有 runScreenshotRecognition(files, mode)
   - 成功後沿用 UX-A toast（已填欄位）
2. **主圖／詳情上傳區**（ImageUploader）：
   - dropzone 或 uploader 容器 onPaste：image 檔 → 走既有 enqueue 上傳管線
3. 非圖片 paste（純文字）→ 不攔截，讓標題等欄位正常貼字
4. 手機：無法完整測 Ctrl+V 可接受；桌機必測。可加小提示「可 Ctrl+V 貼上」muted 一行（非常駐長文）

禁止：新 API；改 Vision prompt。
