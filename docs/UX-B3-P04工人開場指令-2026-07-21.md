4-1 長按進入多選
════════════════════════════════════
常數：LONG_PRESS_MS = 500（與 FAB 一致，可檔頂 export 或本地 const）

僅 isNarrow（沿用 ResultCard／panel 既有窄螢幕判斷；若卡內無 isNarrow，
用 matchMedia max-width 959 或父層傳 isMobile）。

流程：
1. touchstart on 卡片（建議綁 .rc-swipe-front 或 header，勿綁展開後 body 表單）
   - 記錄 startX/startY
   - 啟動 500ms timer
2. touchmove：若 |dx| 或 |dy| > 10px → clear timer（改走滑動／捲動，不進多選）
3. touchend／cancel：clear timer
4. timer 到：
   - 若尚未勾選 → 呼叫 onToggle()（或父層 onLongPressSelect(draftId)）勾上
   - 設 longPressTriggered，吞掉後續合成 click，避免立刻展開卡片
5. 進入多選後（selectedIds.size > 0 或父層 selectMode）：
   - 點其他卡＝toggle 選取（不要展開）
   - 展開改點 ▸／▾ .rc-toggle，或明確「展開」區
6. 取消多選：
   - 在 .rc-batch-strip 加「取消」鈕（手機必顯）：setSelectedIds(new Set())
   - Esc 可選；outside 不強制

Checkbox：
- 不必藏再浮現（現況已顯示）；多選時可加強可見度（.sel 或略放大），非必須

════════════════════════════════════
4-2 左滑快捷（swipe-to-reveal）
════════════════════════════════════
僅 isNarrow + 未展開（expanded 時建議關閉 swipe，避免表單難用）。

結構示意：
<div className="rc-swipe-wrap">
  <div className="rc-swipe-actions" aria-hidden={swipeX === 0}>
    {/* 站別對應的 1～2 顆：與 .rc-quick 同一 onClick */}
  </div>
  <div
    className="result-card …"
    style={{ transform: `translateX(${swipeX}px)` }}
    onTouch…
  >
    …既有 header／body…
  </div>
</div>

或：result-card 為 wrap，內層 .rc-swipe-front 位移——擇一，勿雙重 transform 打架。

邏輯：
- touchstart：記 clientX；若在長按 timer 中且橫移 >10px → 取消長按
- touchmove：delta = clientX - startX；僅允許 delta<0（左滑）；
  setSwipeX(Math.max(delta, -ACTION_W))；ACTION_W ≈ 140
- touchend：swipeX < -ACTION_W/2 → 吸到 -ACTION_W；否則 0
- 點 actions 按鈕 → 既有 quick handler → 收合 swipe（swipeX=0）
- 點其他卡或展開時收合本卡 swipe
- 垂直捲動優先：|dy| 明顯大於 |dx| 時不要鎖橫滑（可 clear swipe 意圖）

快捷按鈕對應（與現有 .rc-quick 一致，勿發明新 API）：
| 站 | 露出按鈕（建議 2 顆內） |
|---|---|
| ① copy_review | 核准、重生 |
| ② image_review | 主操作（標圖通過／送工廠）+ 次要一顆（退回 或 文案預覽） |
| ③ ready | 可不做 swipe 或「發布／匯出」單顆 |
| 封存 | 不做 swipe |

樣式（tokens）：
.rc-swipe-wrap { position: relative; overflow: hidden; }
.rc-swipe-actions {
  position: absolute; inset: 0 0 0 auto;
  width: 140px; display: flex; z-index: 0;
}
.rc-swipe-front { position: relative; z-index: 1; background: var(--surface);
  transition: transform .15s ease-out; }
.rc-swipe-actions .rc-swipe-approve {
  flex: 1; background: var(--accent); color: var(--accent-fg); border: 0;
}
.rc-swipe-actions .rc-swipe-secondary {
  flex: 1; background: var(--surface2); color: var(--text); border: 0;
}
手機 action 鈕 min-height 整卡高或至少 44px；字 12px 可換行。

注意：.result-card 已有 hover transform；swipe 時勿與 --hover-transform 互搶
（可用 .rc-swipe-front 承擔 translateX）。

════════════════════════════════════
手勢互不干擾（必做）
════════════════════════════════════
1. 長按：僅當 500ms 內位移 < 10px
2. 左滑：明顯橫移才更新 swipeX，並 cancel 長按 timer

4. 多選模式中：click＝toggle 選取；不開左滑誤觸可接受（或先收 swipe）
5. 桌機：不掛 touch 邏輯（或掛了也不改變滑鼠 click）
