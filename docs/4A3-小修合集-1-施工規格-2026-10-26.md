## 1. 現況查證（2026-10-26，Claude）

詳情圖怎麼進 Shopify：
- Shopify **商品圖（media）只送主圖＋款式圖**：`src/lib/images/shopifyMainImage.ts` `isShopifyProductMediaImage` 只收 `main`／`variant`。詳情圖從來不會變成 Shopify 商品圖。
- 詳情圖唯一上 Shopify 的路：**商品描述最下面的嵌圖**。`src/lib/shopify/payload.ts:167-176` 呼叫 `appendDescriptionEmbedIfEnabled`（`src/lib/contentGenerator/descriptionEmbed.ts`），最多 2 張：①主圖 ②排序最前的 `detail`，沒有才用 `generated_detail` → 其他 → `variant`。所以每件描述＝1 主圖＋1 詳情圖（老闆 10-25 抽查一致）。
- 詳情圖不會上傳 Shopify Files（`filesUpload.ts` `isFinalizeUploadImageType` 只收 main／variant），所以描述裡那張詳情圖的網址是 Supabase（`…supabase.co/storage/…`）。
- 同一個函式也用在：完整同步（`syncShopifyProduct.ts:602` 呼叫 `buildShopifyProductPayload`）、Matrixify CSV（`src/lib/csv/matrixify.ts:169`）。Showmore CSV 預設不嵌圖，這包不動。
- 已有草稿層級旗標欄位 `product_drafts.image_flags`（jsonb，型別 `Record<string,string>`），現有 `generate_detail`、`vision_status`、`image_review` 都放這裡 → **新旗標放這裡，不用 migration。**（`product_images` 沒有 image_flags 欄位；`showmore.ts` 裡的 `include_on_listing` 是沒接上的舊構想，這包不用它。）

### 2.1 資料
- 旗標：`product_drafts.image_flags.description_detail_ids`（字串，**不用 migration**）。
  | 值 | 意思 | 描述最下面放的圖 |
  |---|---|---|
  | 沒有這個 key（＝**預設**，所有舊商品） | 跟現在一樣 | 主圖＋排最前的 1 張詳情圖（沒有詳情圖才用合成詳情圖→其他→款式圖） |
  | `"none"`（或空字串） | 全部不放 | **只放主圖 1 張**；詳情圖、合成詳情圖都不放，也不拿款式圖補 |
  | `"id1,id2,…"` | 老闆勾的 | 主圖＋勾的詳情圖，**照工具裡詳情圖的排序**（不是勾的先後）；最多 8 張；已刪掉的 id、不是 `detail` 的 id 自動忽略 |
- 已上架 66 件沒有這個 key → 同步時描述**完全不變**，直到老闆在那件商品上動手勾。
- 勾選**不刪任何圖**；沒勾的詳情圖照樣留在工具給 AI 讀字；單張 ✕ 刪除照舊。
- 勾的詳情圖網址仍是 Supabase（這包不搬到 Shopify；搬移與清空間在 **4e STORAGE-SLIM**）。

```ts
/** 4a-3: at most this many detail images the operator can pick into the description. */
export const DESCRIPTION_DETAIL_PICK_MAX = 8;

/**
 * 4a-3: which detail images the description embeds (draft-level image_flags.description_detail_ids).
 * - auto   (key missing / not a string) → current behaviour: main + first detail by sort_order
 * - none   ("none" or empty)             → main image only
 * - picked ("id1,id2,…")                 → main + those detail images, in tool order, max 8
 */
export type DescriptionDetailSelection =
  | { mode: "auto" }
  | { mode: "none" }
  | { mode: "picked"; ids: string[] };

export function readDescriptionDetailSelection(imageFlags: unknown): DescriptionDetailSelection {
  if (!imageFlags || typeof imageFlags !== "object" || Array.isArray(imageFlags)) return { mode: "auto" };
  const raw = (imageFlags as Record<string, unknown>).description_detail_ids;
  if (typeof raw !== "string") return { mode: "auto" };
  const ids = Array.from(
    new Set(
      raw
        .split(",")
        .map((s) => s.trim())
        .filter((s) => s && s.toLowerCase() !== "none")
    )
  );
  return ids.length ? { mode: "picked", ids } : { mode: "none" };
}

/** 4a-3: merge-only write value for image_flags (auto removes the key). */
export function mergeDescriptionDetailSelection(
  existing: unknown,
  selection: DescriptionDetailSelection
): Record<string, unknown> {
  const base =
    existing && typeof existing === "object" && !Array.isArray(existing)
      ? { ...(existing as Record<string, unknown>) }
      : {};
  if (selection.mode === "auto") {
    delete base.description_detail_ids;
  } else {
    base.description_detail_ids =
      selection.mode === "picked" && selection.ids.length ? selection.ids.join(",") : "none";
  }
  return base;
}
```

```ts
/**
 * 4a-3 UI: which detail images the description embeds for this draft — ids (tool order) and their
 * 1-based positions among the draft's detail images.
 */
export function describeDescriptionDetail(
  images: DescriptionEmbedImageInput[] | null | undefined,
  imageFlags: unknown
): { mode: DescriptionDetailSelection["mode"]; ids: string[]; positions: number[] } {
  const selection = readDescriptionDetailSelection(imageFlags);
  const details = (images ?? [])
    .filter((img) => img.image_type === "detail")
    .sort((a, b) => a.sort_order - b.sort_order);
  const embedded = new Set(
    pickDescriptionEmbedImages(images, null, DESCRIPTION_EMBED_MAX, { detailSelection: selection })
      .filter((p) => p.imageType === "detail")
      .map((p) => p.id)
  );
  const ids: string[] = [];
  const positions: number[] = [];
  details.forEach((img, index) => {
    if (!embedded.has(img.id)) return;
    ids.push(img.id);
    positions.push(index + 1);
  });
  return { mode: selection.mode, ids, positions };
}

/**
 * 4a-3 UI: click「放描述」on one detail image. Starts from what the description embeds now
 * (auto counts as its one image); empty → none; over the max → "over_max" (nothing written).
 */
export function toggleDescriptionDetailPick(
  images: DescriptionEmbedImageInput[] | null | undefined,
  imageFlags: unknown,
  imageId: string
): DescriptionDetailSelection | "over_max" {
  const current = describeDescriptionDetail(images, imageFlags).ids;
  const next = current.includes(imageId)
    ? current.filter((id) => id !== imageId)
    : [...current, imageId];
  if (next.length > DESCRIPTION_DETAIL_PICK_MAX) return "over_max";
  if (!next.length) return { mode: "none" };
  const order = new Map(
    (images ?? [])
      .filter((img) => img.image_type === "detail")
      .map((img) => [img.id, img.sort_order] as const)
  );
  next.sort((a, b) => (order.get(a) ?? 0) - (order.get(b) ?? 0));
  return { mode: "picked", ids: next };
}
```

## 3. ② 商品庫搜尋 `src/lib/library/productLibrary.ts`

```ts
/**
 * 4a-3: search text normalize — full-width → half-width (NFKC), lowercase, 「|」「｜」 treated as a
 * space, whitespace collapsed. Applied to the query and to every searched field.
 */
export function normalizeLibrarySearchText(value: string | null | undefined): string {
  return (value ?? "")
    .normalize("NFKC")
    .toLowerCase()
    .replace(/[|｜]/g, " ")
    .replace(/\s+/g, " ")
    .trim();
}
```

## 4. ③ OpenAI 429 中文提示

### 4.1 新檔 `src/lib/drafts/aiErrorMessage.ts`（照抄）

```ts
/**
 * 4a-3: operator-facing wording for OpenAI 429 errors. Display only — the raw error stays in
 * product_drafts.generation_error / generation_runs.error_message for debugging.
 */

export const AI_QUOTA_EXHAUSTED_MESSAGE = "OpenAI 額度用完了：請到 OpenAI 後台儲值，再重新生成";
export const AI_RATE_LIMITED_MESSAGE = "OpenAI 暫時太忙（429）：稍等一兩分鐘再重新生成";

/** Only OpenAI 429 texts are rewritten; anything else is returned unchanged (trimmed). */
export function humanizeAiError(text: string | null | undefined): string {
  const raw = (text ?? "").trim();
  if (!raw) return raw;
  if (!/openai/i.test(raw) || !/\b429\b/.test(raw)) return raw;
  if (/insufficient_quota|credit_balance|no credits remaining|exceeded your current quota/i.test(raw)) {
    return AI_QUOTA_EXHAUSTED_MESSAGE;
  }
  return AI_RATE_LIMITED_MESSAGE;
}
```
