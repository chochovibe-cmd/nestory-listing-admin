## 核心命名衝突

### 問題 1：「生圖工廠」vs「圖片審核」

Mockup 叫「圖片審核」，但實作改成「生圖工廠」（R2 §14 決策）。功能是：使用者在這裡審核 AI 生成的圖片、決定核准或退回重生。

### 問題 2：手機 tab「審核」

手機 tabbar 的「審核」指的是「看結果卡片列表（文案審核）」，不是圖片審核。兩者容易混淆。

---

## 方案選項（老闆選一個）

### 方案 A：保持現狀（生圖工廠 + 審核）

| 位置 | 名稱 |
|------|------|
| 側欄 | 生圖工廠 |
| 手機 | 工廠 / 審核 / 新增 |

- 優點：不需改動
- 缺點：「審核」和「工廠」都有審核功能，新使用者困惑

### 方案 B：統一用「功能動詞」命名

| 位置 | 名稱 |
|------|------|
| 側欄 #2 | **標圖** |
| 手機 tab 左1 | **文案** |
| 手機 tab 左2 | **標圖** |

- 優點：動詞清晰、不衝突（文案 = 看/審文案，標圖 = 標記圖片）
- 缺點：「標圖」可能不夠正式

### 方案 C：混合（側欄完整、手機精簡）

| 位置 | 名稱 |
|------|------|
| 側欄 #2 | **圖片工廠** |
| 手機 tab 左1 | **結果** |
| 手機 tab 左2 | **圖片** |

- 優點：手機用最精簡的名詞，一看就懂
- 缺點：「圖片工廠」稍冗長
