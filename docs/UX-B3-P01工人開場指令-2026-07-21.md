問題根因（已對照程式碼確認，2026-07-21）
════════════════════════════════════
截圖卡結構（約 L2145–2231）：

.outer .source-card--shot
  onClick={() => productShotInputRef.current?.click()}   // 開檔案選擇窗

根因：
paste 輸入框的 stopPropagation 會擋住點擊冒泡到外層卡片，

老闆要的是：桌機「點輸入框也能選檔」＋「Ctrl+V 貼上」兩種都要；
手機多數用相簿，不需要假輸入框。
