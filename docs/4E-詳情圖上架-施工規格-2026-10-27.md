## 1. 查證：為什麼現在詳情圖沒上 Shopify（10-27，handoff d8e5723）

1. **上傳 Shopify Files 只做主圖＋款式圖**：`filesUpload.ts` `isFinalizeUploadImageType()` 只有 `main`／`variant` 回 true；詳情圖要傳 `retainForListing: true`，但**沒有任何呼叫端傳**（`runFinalize.ts:218`、`prepareImagesForPublish.ts:61`）。最早的設計是「詳情圖只給 AI 讀、不上架」。
2. **同步完全不跑上傳**：`syncShopifyProduct.ts` 沒呼叫 `prepareImagesForPublish`／`runFinalizeForDraft`；只有發布（`publishDraftSafe.ts:597`）會跑。
3. **描述只嵌 2 張**：`descriptionEmbed.ts` `DESCRIPTION_EMBED_MAX = 2`（主圖＋1 張詳情圖），網址直接用 `processed_file_url`（詳情圖＝Supabase）。
4. **Shopify 不會幫描述裡的圖搬家**：商品圖庫（media）用 `originalSource` 給網址，Shopify 會自己複製一份；但描述 HTML 裡的 `<img src>` 是原樣顯示 → 客人每看一次商品頁就從 Supabase 下載一次（免費流量 5GB／月）。
5. **同步不能順便把主圖／款式圖也換成 CDN**：`matchImages()`（`syncShopifyProduct.ts:295-305`）用網址算 `sourceHash`，網址一變就會叫 Shopify 重傳商品圖 → 這包同步時**只上傳詳情圖**，主圖在描述裡改用「Shopify 商品現在的第一張圖」網址。

正式資料（唯讀，10-27）：詳情圖 1,168 張全在 Supabase（已上架商品身上 805 張，最多一件 20 張，近期平均約 220KB／張）；`generated_detail` 6 張（4 張原圖已在 CDN）；已上架 67 件。

## 2. 規則（寫死，測試都有對應）

- **放哪些圖、什麼順序**：Shopify 主圖（`pickShopifyMainImage`，跟商品圖第一張同一張）→ `generated_detail`（照 `sort_order`）→ `detail`（照 `sort_order`）。款式圖、規格圖不放。**沒有張數上限**。同網址只放一次。
- **只放 Shopify CDN 網址**：每張依序找 `processed_file_url` → `original_file_url` → `generated_file_url` 第一個是 CDN 的；都不是就**這次不放**（不准退回 Supabase 網址）。
- **主圖網址**：主圖列本身有 CDN 網址就用；沒有時，同步傳入 Shopify 商品目前第一張 IMAGE 的網址（也必須是 CDN）；都沒有就不放主圖。
- **開關**：`product_drafts.image_flags.description_detail_images`，沒設＝開；`"false"`（或 false／0／"0"／"off"／"no"）＝關。**關＝描述一張圖都不放**（主圖也不放）。不用 migration（`image_flags` 已是 jsonb）。總開關環境變數 `DESCRIPTION_EMBED_IMAGES=off` 照舊優先。
- **HTML 格式不變**：照舊 `<!-- nestory-desc-embed -->` 開頭、每張 `<p><img src alt loading="lazy" style="max-width:100%;height:auto;" /></p>`，位置照舊在內文之後、內部連結與 FAQ 結構化資料之前 → 對帳比對（`descriptionCompareText`）照舊忽略圖片區，開關切換或圖片增減**不會**被當成「描述被改」。
- **上傳**：只傳「要放、但還不是 CDN」的詳情圖；一次最多 4 張並行；開始後超過 120 秒不再開新的；成功寫 `processed_file_url`＝CDN、`processing_status`＝done、`processing_error`＝null；**不改 `original_file_url`、不刪 Supabase 檔**（給 AI 讀字照舊讀 `vision_mid_url`／`original_file_url`）；不寫 `shopify_file_id`（那欄是商品圖 media 用的）。
- **失敗不擋發布／同步**：失敗或來不及的那幾張這次不放進描述，警告文字固定：
  - `詳情圖上傳 Shopify 失敗 N 張，這次沒放進描述；再同步一次會補上`
  - `詳情圖還有 N 張來不及上傳，這次沒放進描述；再同步一次會補上`
  - 發布：照舊加「發布前圖處理：」前綴寫進 `product_drafts.warnings`；同步：加進同步結果的 `warnings`。
- **重跑不重傳**：已是 CDN 的直接跳過。
- **發布**：`prepareImagesForPublish` 之後、重新讀草稿之前上傳（主圖這時已是 CDN）。**同步**：讀完 Shopify 現況、`unsafe_remote_status` 檢查之後、`buildSyncDesiredState` 之前上傳。開關關或總開關關就整段跳過。
- **測試保護**：有注入 `deps.callGraphQL`（測試）但沒注入 `deps.uploadDescriptionImages` 時跳過上傳，不准打真的 Shopify Files。
- **CSV（Matrixify／Showmore）不在這包**：照舊用 `appendDescriptionEmbedIfEnabled`。
