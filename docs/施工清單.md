> 1. 每個 session 開始：讀本清單 → 跟使用者確認本次要做哪 3–5 項（一次不要超過 5 項）
> 2. 做的時候只讀「該項標註的參考文件」，不用重讀全部文件
> 3. session 結束前：把完成的項目打勾 `[x]`、註記日期，未完成的寫一行原因
> 4. 發現清單沒涵蓋的新需求 → 先加進清單再做，不要做完沒記錄
