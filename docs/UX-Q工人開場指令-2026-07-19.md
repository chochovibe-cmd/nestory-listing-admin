施工清單：
「批次工具列 ▶ 逐件審核 → 全螢幕一次一卡，核准即自動下一張；
 桌機快捷鍵（→ 下一件、A 核准、1–5 切卡片分頁）」

指揮定案：

1. **入口**
   - 站①（copy_review）批次工具列加 **「▶ 逐件審核」**（主動作級或與批次列並列）
   - 佇列來源優先：
     a) 若有勾選 → 依目前可見列表順序，只走**已勾選**且屬站① 的草稿
     b) 若無勾選 → 走**目前站① 可見列表全部**（與篩選一致）
   - 0 件：toast「沒有可審的文案」不開模式

2. **呈現**
   - 全螢幕（或近全螢幕）overlay：一次只顯示 **一張** ResultCard（展開）
   - 頂欄：第 i／N、標題短句、**結束逐件**（Esc 同）
   - **重用 ResultCard**，禁止複製整卡業務邏輯
   - 樣式：tokens only；手機 overlay 可 bottom-sheet 高比例（max-height ~92vh 可捲）

3. **核准後自動下一張**
   - 使用者在卡上按既有「核准」成功後 → 自動進佇列下一件
   - 實作：ResultCard 核准成功 callback（onApproved／既有 refresh 後）由 SequentialReview 推進 index
   - 最後一件核准完 → toast「逐件審核結束」並關閉模式
   - 失敗：留在本卡，toast error，不跳下一張

4. **桌機快捷鍵**（僅 sequential mode 開啟且 focus 不在 input/textarea 時）
   | 鍵 | 行為 |
   |---|---|
   | → 或 j | 下一件（未核准也可跳過） |
   | ← 或 k | 上一件 |
   | A | 觸發本卡核准（等同點核准鈕；busy／double-confirm 規則跟卡一致） |
   | 1–5 | 切卡片分頁（對應目前站可見 tab 順序，如 文案=1 規格=2 定價=3…；站① 無圖片） |
   | Esc | 結束逐件模式 |

   - 輸入中文／textarea 時不搶鍵（對齊 UX-I Ctrl+Enter 規則）
   - 可選：? 顯示快捷鍵小提示（muted 一行）

5. **站②／③**
   - 本包 **預設只做站①**（核准文案）
   - 站② 逐件「標圖通過」若時間夠可加同一殼（修法清單註明做／不做）；不做不算失敗

6. **只加不減**
   - 批次核准／勾選／既有流程全保留
   - 不重做 double-confirm 語意

驗：
