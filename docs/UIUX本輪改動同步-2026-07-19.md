## 3. 行為細節（接續者必讀）

### BX2 Undo（`src/lib/drafts/quickUndo.ts` + Toast action）

| 動作 | 復原方式 | 備註 |
|---|---|---|
| 核准文案 | `POST /api/drafts/:id/return-stage` `target=copy_review` | 會變 needs_revision 語意站① |
| 標圖分流（待發布／送工廠） | 同上 `target=image_review` | **送工廠 best-effort**；深處理可能清不乾淨 |
| 封存 | `POST /api/drafts/batch/archive` `unarchive` | notice 復原鈕仍保留 |

- Toast 支援 `showToast(msg, variant, ms, { actionLabel: "復原", onAction })`  
- 契約：`src/lib/toast/toastEvents.ts`（`actionLabel` + `toastActionCallbacks`）  
- UI：`src/components/Toast.tsx`（`.toast-main` + `.toast-action`）  
- **S1 秒數分級**（`UNDO_TOAST_MS` in `quickUndo.ts`）：核准／封存／待發布 **10s**；送工廠 **15s**；卡內封存 timer 同常數。發布 Shopify 無 toast 復原

### BX1 延伸：站② 逐件標圖

- 入口：`DraftResultsPanel` 標圖站 **▶ 逐件標圖**（不需先勾選；有勾＝只審勾選）  
- `SequentialReviewOverlay`：`mode="copy" | "image"`  
- 站②：`A`＝`stationReview()`（兩次確認）；成功呼叫 `onApproveSuccess` 進下一張  
- ResultCard：`sequentialStation="image"` 預設打開圖片分頁  

### BX5 批次 busyLabel

- `DraftResultsPanel`：`busyLabel` 顯示在主批次鈕上  
- 例：核准中 N 筆、分流中 1/2、開詳情圖 k/n

### BX6 手機 tabbar

- 版面：**審核｜工廠｜中央凸起＋新增｜更多**  
- `src/components/MobileTabbar.tsx`、`src/lib/nav.ts`（`MOBILE_SIDE_TABS`）  
- CSS：`.mtb-fab`、`.mobile-tabbar--fab`；`--tabbar-h: 72px`（≤959px）

### BX7 成本粗估

- `src/lib/drafts/generateCostHint.ts` → `buildGenerateCostHint`  
- 依：模型 claude/openai、主圖+詳情張數、Web Search、測試模式 $0  
- 文案固定含「**僅供參考**」；**不是帳單**  
- ImageUploader 新增 `onCountsChange({ main, detail })`

### BX9 Lightbox

- `src/components/review/ImageLightbox.tsx`  
- 接在 `ImageCompareSlider`（生圖工廠）  
- 滾輪縮放、雙指 pinch、Esc／點背景關閉

### BX10 語氣記憶

- `src/lib/drafts/toneMemory.ts`  
- key：`localStorage["nestory_tone_by_ip"]`  
- 寫入：表單生成成功（`detectedIpName`）、卡片重新生成  
- 讀取：標題含 IP 名且目前仍是預設語氣時自動帶；開重生 modal 預填  
- API：`/api/generate` 成功 JSON 多回 **`detectedIpName`**

### SYN-1 生成詳情圖 UI

- Flag：`product_drafts.image_flags.generate_detail`（缺省＝開，見 `isGenerateDetailEnabled`）  
- 單卡：`Station2ImagePanel` 頂部 toggle  
- 批次：站②「更多」→ 開·生成詳情圖／關·生成詳情圖  

### A19 雙尺寸上傳

- `src/lib/images/clientImageResize.ts`：瀏覽器產 ~1280 mid ＋ ~320 thumb  
- `ImageUploader`：mid → thumb → 原圖；DB 寫 `list_thumb_url`／`vision_mid_url`  
- migration **039**（**已執行**）；舊環境若缺欄仍會 **降級**只寫原圖 URL  
- `analyze-images`：優先 `vision_mid_url`  
- 列表／卡 thumb：優先 `list_thumb_url`  

### D9 商品頁預覽（示意 + Shopify iframe）

- `ExportPreflightModal` 第三 tab「商品頁預覽」：  
  - **示意預覽**：標題／價／圖／介紹  
  - **Shopify 官網**：iframe `https://{SHOPIFY_STORE_DOMAIN}/products/{handle}`  
- Admin URL **永不 iframe**（X-Frame 必擋）  
- 商店禁止嵌入 → 空白時用「新分頁開啟官網」  
- 網域：`GET /api/status` → `shopifyStoreDomain`；client 快取 `clientStoreDomain.ts`  
- 無 handle 或無商店網域 → 官網分頁 disabled  

### BX-P 第一刀（儀表板）

- 頁頂 disclaimer 一次說清「估算非帳單」  
- 額度／成本：**去掉常駐「估算」chip**（只留接近上限／預算黃字）  
- 桌機 ≥720px：`.dash-metrics-grid` 兩欄（額度｜成本）  
- **不要**再開無截圖的零碎美化；第二刀等老闆截圖  

### T112-r3 胖鈕（老闆截圖）

- 根因：footer 裸 `button` 吃全域 `min-height: 38px`；sh-mode pill 寫死 44  
- 修：desktop pill／act-btn 瘦身；手機 ≥44
