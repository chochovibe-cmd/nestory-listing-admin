【T34】頂欄減重（高頻 vs 設定／次要）
────────
痛點 R57：頂欄把商品庫／AI／測試模式／部署／連線／匯率／主題／登出全攤開，手機尤甚；
設定頁與頂欄功能重疊。

指揮定案（核帳對這 4 點）：
1. **常駐頂欄（高頻）**只留：
   - 🔍 商品庫（已登入）
   - 匯率顯示（ExchangeRateWidget——只顯示，不在頂欄改匯率，對齊既有差異備忘）
   - 主題切換（ThemeSwitcher）
   - 帳號／登出（AuthNav）
2. **次要工具收納**（不可刪除功能，只搬家）：
   - ProviderSwitcher（AI 模型）
   - ModeSwitcher（正式／測試等）
   - DeploymentStatus（部署／環境）
   → 放進頂欄 **「⋯ 更多」**（或「工具」）下拉／popover **一層**；
     桌機、手機 ☰ 選單內都走同一套：常駐項平鋪、次要在「更多」內。
3. **設定頁**：若 Settings 已有「AI 模型／連線狀態」——保留單一來源說明即可；
   **不要**為了減重去砍 Settings 既有區塊；也不要在設定再複製一整排與「更多」完全同 UI 的第二套開關（可加一行 muted：「工作檯頂欄 ⋯ 也可切換本次模型／模式」）。
4. **只加不減**：能力不得消失；鍵盤／觸控 ≥44px（手機 ☰ 內按鈕）；三主題可用。

動檔建議：HeaderControls.tsx、globals.css（.hdr-more 等沿用 .hdr-btn／既有 nav 樣式）、必要時抽小元件 HeaderToolsMore.tsx。
不要動 AppSidebar 頁面導覽（頁導覽已在側欄／tabbar）。

驗：桌機 1280 頂欄明顯變短；手機 ☰ 打開後一級不塞爆；Provider／Mode／Deploy 仍可切且行為與改前一致。

【T45】空狀態設計（結果／工廠／紀錄）
────────
痛點 BX8／體檢：空畫面各自為政，有的只有一句 notice、有的缺主 CTA。

指揮定案：
1. **統一骨架**（沿用既有 `.empty-state` + `.empty-icon` + muted 一句 + 可選 primary CTA）：
   - 圖示（可用既有 ◈ 或與頁面一致的 emoji，勿新引入圖庫）
   - **一句**主文（發生什麼）
   - **一個**主行動（去哪裡解決）——有合理目的地才放；沒有就不硬塞
2. **三處最低標**：
   | 畫面 | 空時主文方向 | CTA |
   |---|---|---|
   | 結果區（DraftResultsPanel） | 維持 UX-E：無佇列／篩空／清除篩選——**只統一樣式層級，不回退 T33** | 去新增／清除篩選 |
   | 工廠（ImageReviewPanel） | 「目前沒有要審的圖」類 | 去工作檯新增 或 回工作檯（已有 Link 可強化樣式對齊 .empty-state） |
   | 紀錄（PublishRecordsPanel） | 各 tab 空：「尚無發布批次／尚無失敗件…」 | 有合理時給「去工作檯」；無則僅文案 |
3. **禁止**：假資料填空、改 API、大段說明文（資訊密度：工程師註記不上畫面）。
4. 快速預覽 `quick-preview-empty` 可一併對齊字級／留白，**非本包必改**若時間不夠可略。

動檔建議：globals.css 強化 `.empty-state` 共用；ImageReviewPanel／PublishRecordsPanel 套用；DraftResultsPanel 僅對齊 class。

驗：三頁空狀態看起來像同一家人；手機 375 不擠、CTA ≥44px。

【T48】儀表板排版減重複標語
────────
痛點 R56：資訊正確但擁擠；「估算·非帳單」類標語重複多次。

指揮定案：
1. **頁級免責一次**：在 `dash-header`（標題列）或頁頂放 **一行** 總提示，例如：
   「以下額度／成本為估算，非實際帳單」
2. **各 panel 標題旁**的 `dash-todo-hint`：
   - Make 額度／AI 成本：**拿掉**重複的「估算 · 非…帳單」；可改短標（如「本月」）或乾脆不放 hint
   - 今日待辦／漏斗／健康：保留**有資訊差**的 hint（如「積壓待辦 · 不限今天」），不要全刪成空白牆
3. **版面**：略增 panel 間距／section 呼吸感（用既有 gap／padding token 或現有 spacing 尺度）；**不**重做資料卡邏輯、不改 fetch、不改數字。
4. 副標 `ir-sub`「初版 · 待辦＋…」可縮成更短（如「待辦 · 漏斗 · 成本」），避免與各 h2 重複念一整串。

動檔：DashboardTodoPanel.tsx、globals.css 的 `.dash-*` 間距即可。

驗：掃一眼只看到 **一處**「非帳單／估算」總提示；數字與改前一致；三主題＋手機可捲不爆。
