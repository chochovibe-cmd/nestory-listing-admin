# v0.1 Status Report

Updated: 2026-06-24

## Completed

- Next.js PWA scaffold with safe `.env.example` and `.gitignore`.
- PWA manifest and icon are present under `public/`.
- Supabase schema for team roles, product queue, images, generation runs, publish jobs, automation logs, and review logs.
- RLS foundation for `admin`, `operator`, and `reviewer`.
- Database trigger guard blocks non-reviewer users from changing generation/publish system fields, `publish_mode`, or escalating drafts into review/publish states.
- Product image RLS limits operator image writes to own drafts in input/review-prep states.
- Supabase Storage bucket plan for `product-images`.
- PWA routes:
  - `/drafts/new`
  - `/drafts`
  - `/review`
  - `/drafts/[id]`
- `/login`, `/drafts`, `/drafts/new`, and `/review` render a setup notice instead of throwing when Supabase public env is not configured.
- Local preview helper:
  - `scripts/start-local.ps1`
  - Starts the built PWA at `http://127.0.0.1:<port>/login`.
- Product drafts default to:
  - `status = pending_copy`
  - `generation_mode = codex_skill`
  - `generation_provider = codex`
  - `publish_mode = active`
  - `publish_method = shopify_api`
- Worker scoped API:
  - `POST /api/worker/claim`
  - `POST /api/worker/complete`
  - `POST /api/worker/fail`
  - Claim uses SQL `FOR UPDATE SKIP LOCKED` to avoid duplicate processing.
  - The claim RPC is executable by `service_role` only; workers must use the scoped API.
- Reviewer-only approve API:
  - `POST /api/drafts/[id]/approve`
- Reviewer-only request revision API:
  - `POST /api/drafts/[id]/request-revision`
- Mock-safe Shopify publish API:
  - `POST /api/drafts/[id]/publish`
  - Requires `confirmActive=true` for active mode.
  - Defaults to `SHOPIFY_PUBLISH_MOCK=true`.
- Matrixify CSV fallback:
  - `POST /api/exports/matrixify`
  - Supports single or batch draft IDs.
  - `Option1 Name` uses the standard Matrixify value `Title`.
- Make webhook notifications are scaffolded for:
  - `ready_for_review`
  - `generation_failed`
  - `active_published`
  - `draft_created`
  - `api_failed`
  - `csv_ready`
