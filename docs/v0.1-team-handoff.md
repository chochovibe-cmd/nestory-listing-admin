## Local Operator Runbook

Use this when handing off to someone who only needs to preview the app locally:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start-local.ps1 -Port 3018 -Build
```

Then open:

```text
http://127.0.0.1:3018/
http://127.0.0.1:3018/login
```

To smoke-test the running app:

```powershell
node scripts/verify-pwa-smoke.mjs http://127.0.0.1:3018
```

The smoke test is intentionally read-only. It does not create drafts, upload
images, claim worker jobs, approve reviews, publish, or export CSV.
