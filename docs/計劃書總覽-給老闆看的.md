## 一、這個工具最終長什麼樣（一句話＋一張流程）

**貼標題＋丟圖片 → AI 產文案跟圖片 → 你審核 → 一鍵上架 Shopify（Showmore 匯 CSV）→ 儀表板看成果。**

```text
你輸入（標題/圖片/成本，2分鐘）
   ↓ 按「生成」
AI 自動：辨識圖片 → 判斷IP角色 → 寫文案 → 算價格（你可以繼續填下一件）
   ↓
你審核文案（改字、挑版本、標記圖片要不要重做）→ 按核准
   ↓
背景自動：生圖/去簡體字 → 好了寄 Email 給你
   ↓
你審核圖片（滑桿比對）→ 確認
   ↓
一鍵發布 Shopify ＋ 匯出 Showmore CSV → 發布紀錄留底
```

## 三、六個階段白話說明

### Phase A｜接上真的引擎（後端，看不到畫面變化）
- **做什麼**：接真 Shopify 發布、讓 AI 真的看得到圖片（Vision）、更新文案 Prompt、標題去重
- **做完你會看到**：按核准後，Shopify 後台真的出現草稿商品；文案開始引用圖片細節
- **你要準備**：Shopify Admin API token（勾 write_products＋write_files 兩個權限）
- **驗收**：⭐ 一件真商品跑完全程，親眼去 Shopify 後台看
- 項目 A0–A17，約 4–6 個工作 session

### Phase B｜前台大整修（感受最明顯的階段）
- **做什麼**：修掉「填完資料才冒出圖片上傳」的怪流程——改成一個畫面填完、圖片先選、
  按生成就走；卡片改分頁式；批次按鈕置頂；畫面減文字加留白
- **做完你會看到**：上架一件商品的手感變順，手機也好用
- **驗收**：⭐ 找一位沒看過工具的同事，不講解，3 分鐘內完成一件上架
- 項目 B1–B18，約 6–8 個 session（最大的階段）

### Phase C｜殼與設定（把家具歸位）
- **做什麼**：側邊收合選單、設定頁分類收合（含 System Prompt 版本管理、成員管理、
  Showmore 加價、匯率套用）、商品庫彈窗、發布紀錄頁
- 項目 C1–C6，約 3–4 個 session

### Phase D｜圖片自動化（第二段生產線）
- **做什麼**：圖片背景處理（去簡體字/重生/賣點圖）、Make 串接、批次 Email 通知、
  圖片審核頁（滑桿比對）、Showmore 改寫版文案＋圖包匯出
- **你要準備**：GPT Image 用的 key（你現有的 OpenAI key 就行）、Make 帳號（免費版）
- 項目 D1–D9，約 5–7 個 session（技術上最複雜，Opus 出場率最高的階段）

### Phase E｜儀表板（開始有經營感）
- **做什麼**：今日待辦卡、流程漏斗、成本明細、月預算提醒、Make 額度錶；後段加 AI 顧問卡、競品比價
- **你要準備**：（後期）GSC 網站驗證
- 項目 E1–E6，約 2–3 個 session

### Phase F｜選品情報（最後的甜點）
- **做什麼**：口袋清單（隨手存連結）→ 手機捷徑一鍵存 → 商家每週掃描（預設關閉，你開才跑）
- **你要準備**：（最後）Hostinger VPS 租用（約 NT$150/月，跑 n8n＋爬蟲）
- 項目 F1–F3，約 2–3 個 session

## 四、你的日常節奏（實作期間）

1. 開新對話 → 貼操作手冊「情境 1」的開場白
2. 模型回報進度＋這次要做哪 3–5 項 → 你確認
3. 它做完 → 你問「對照施工清單，念出完成了哪幾項」→ 看截圖驗收
4. 打勾、關對話。下次再開新的
5. 模型選擇：**每個 Phase 第一個 session 用 Opus 規劃，其餘 Sonnet**；同一問題修兩次沒好換 Opus

## 六、十條保命原則（背下來的話，其他都可以忘）

1. **一個對話只做 3–5 項，做完開新的**——防模型失憶
2. **收工必問「對照清單念出完成了哪幾項」**——防漏做
3. **真品實測後才量產**——一件真商品跑全程
4. **SQL 自己貼、key 進環境變數、push 前先問**——安全三紅線
5. **功能照 Mockup、長相照現網站（分支三主題）**——防風格走鐘
6. **一次只改一件事**——加功能和改風格不要混在一起講
7. **給截圖不給形容詞**——改風格時參照物勝過一百句描述
8. **大改風格開「試衣間」**（做成新主題切換比較），不覆蓋現有的
9. **想被記住的寫進檔案，不想被照抄的寫成禁令**——對話會忘，檔案不會
10. **挑三篇你最滿意的自寫文案給模型當範例**——品牌口吻的靈魂，只有你能給
