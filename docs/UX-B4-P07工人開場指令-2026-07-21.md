1) CSS Grid 的 `1fr` 預設等同 minmax(auto, 1fr)，**右欄最小寬度被內容撐開**。

3) 繪製順序：DOM 先左後右 → **結果卡蓋在表單上面**。
   老闆截圖：左「原始商品標題」框被右邊 Razer／YOSIDA 結果卡蓋住＝此現象。

4) 左欄固定 420px 但子元素若無 min-width:0／max-width:100%，
   長標題／長 URL 也可能向右溢出與結果卡交錯。
